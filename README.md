# Система денежных переводов на Go

Учебный проект консольной системы денежных переводов между пользователями. Проект демонстрирует эволюцию архитектуры: от базовых структур и методов до параллельной обработки транзакций и синхронизации потоков.

## Требования и запуск

Для запуска проекта необходим установленный Go.

Запустите программу:
```bash
go run .
```

## Описание версий по веткам

* **v1 (Часть 1: Основы ООП и структуры)**
  * Создана структура `User` с полями `ID`, `Name` и `Balance`.
  * Реализованы методы пополнения счета (`Deposit`) и списания (`Withdraw`) с проверкой остатка на балансе и возвратом ошибки.
  * В `main` продемонстрированы последовательные операции над пользователями.

* **v2 (Часть 2: Модель транзакций и контейнер системы)**
  * Добавлена структура `Transaction` (`FromID`, `ToID`, `Amount`).
  * Реализована структура `PaymentSystem` с хранилищем пользователей (`map[string]*User`) и очередью транзакций (`[]Transaction`).
  * Добавлены методы `AddUser`, `AddTransaction` и функция процессинга `ProcessingTransactions`.

* **v3 (Часть 3: Конкурентность и Worker Pool)**
  * Реализован паттерн Worker Pool для обработки задач.
  * Добавлен буферизованный канал `chan Transaction` размером в очередь транзакций.
  * Создан метод `Worker` для параллельной обработки данных из канала с помощью цикла `for range`.
  * Запуск 3 воркеров в отдельных горутинах и координация их завершения через `sync.WaitGroup` и закрытие канала (`close`).

* **v4 (Часть 4: Потокобезопасность и устранение Data Race)**
  * Решена проблема состояния гонки данных при параллельном доступе к пользователям.
  * В структуру `User` добавлен мьютекс (`sync.Mutex`).
  * Методы `Deposit` и `Withdraw` защищены блокировками `Lock()` и `defer Unlock()`.
